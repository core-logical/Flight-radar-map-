✈️ Flight Radar
A Python-based flight tracking application inspired by Flightradar24.

About the Project:
This project aims to provide a simple way to explore and track aircraft using Python.

Features:
Flight tracking
Aircraft information
Simple and intuitive interface
Technologies
Python

Clone the repository.
Install the required dependencies.
Run the application.
